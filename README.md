# Vokabeltrainer
Vokabeltrainer für Kids

Eigene Vokabellisten können aus einem Schulbuchfoto erstellt werden. Die Texterkennung läuft im Browser auf dem Gerät; das Foto wird nicht hochgeladen. Die OCR-Engine wird bei der ersten Nutzung aus dem Internet geladen. Erkannte Wortpaare vor dem Speichern prüfen und korrigieren.
